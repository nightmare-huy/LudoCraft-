# FTB Evolution 1.47.0 — первый консервативный баланс Лудки

**LudoCraft 1.5.0 · Minecraft 1.21.1 · NeoForge 21.1.265 · экспериментальный профиль.**
Это отдельный opt-in preset, а не глобальная замена цен для всех сборок.
Без его datapack Лудка сохраняет баланс 1.4.0. Кирка 85/15 не изменена.

## Установка

1. Установить `ludocraft-1.5.0.jar` **и на клиент, и на сервер**, удалить старый JAR.
2. Взять `ludocraft-1.5.0-ftb-evolution-1.47.0.zip` из того же [релиза](https://github.com/nightmare-huy/LudoCraft-/releases/tag/v1.5.0).
3. Положить ZIP целиком в `<папка мира>/datapacks/`. В одиночной игре это
   `saves/<мир>/datapacks/`, на сервере — datapacks именно серверного мира.
   **Не класть ZIP в mods**, не вкладывать его в другой datapack.
4. Закрыть Лудку, выполнить `/reload`, проверить `/datapack list enabled`.
   Если пакет отключён, выполнить
   `/datapack enable "file/ludocraft-1.5.0-ftb-evolution-1.47.0.zip" last`.
5. Открыть Лудку заново: заголовок **«ЛУДКА · EVOLUTION 1.47.0»** подтверждает активацию.
   Контрольные цены: алмаз **32**, железный слиток **8**, незеритовый слиток **512**.

Пакет нужен только миру/серверу: Minecraft синхронизирует теги клиентам.
Наличие Mekanism/FTB Materials не включает профиль автоматически и не доказывает
версию сборки. Для возврата к универсальным ценам удалить/отключить ZIP и выполнить
`/reload`, предварительно закрыв меню. Не менять профиль во время прокрутки:
уже начатый результат остаётся замороженным, новая цена действует на следующие ставки.

Исходник ZIP: [`compat/ftb-evolution-1.47.0`](../../compat/ftb-evolution-1.47.0).
Сборка: `./gradlew evolutionPack`. ZIP содержит `pack.mcmeta` в корне.

## Цены и шансы

| Предмет | Универсальный 1.4.0 | Evolution preset |
|---|---:|---:|
| Железный слиток / блок | 16 / 144 | 8 / 72 |
| Алмаз / блок | 128 / 1152 | 32 / 288 |
| Изумруд | 96 | 16 |
| Незеритовый слиток / пыль FTB Materials | 2048 / по тегам | 512 / 512 |
| Новый обычный лук | 768 | 16 |
| Звезда Незера | 8192 | 512 |
| FTB Materials osmium: сырьё / слиток / блок сырья | по тегам | 6 / 12 / 54 |
| AE2 controller / drive | 1024 / 512 | 2048 / 1024 |
| AE2 item cell 1k | 384 | 640 |
| AE2 item cell 4k / 16k / 64k | 640 / 1152 / 2176 | 1664 / 4736 / 13952 |
| AE2 item cell 256k | 4224 | 32767 |
| MEGACells 1m–256m | разные цены | все 32767 (потолок) |

Согласованы обычные формы материалов, имена FTB Materials и материальные `c:`-теги
других модов. Известные профили машин 1.4.0 сохраняются, если нет явной поправки.
Компоненты ячеек растут примерно по тройной цепочке до потолка 32767; за корпус и
portable-версию прибавляется фиксированная цена, также ограниченная потолком.

Примеры, по одному предмету ставки:

- Алмаз → AE2 controller: **6.2500% → 0.7812%**.
- Алмаз → AE2 item cell 1k: **16.6666% → 2.5000%**.
- Алмаз → незеритовый слиток: **3.1250%**, отношение цен сохранено.
- Земля → незерит: **0.0976%**. Профиль не снижает абсолютно все шансы: доступные
  автоматизации материалы дешевеют и как награды, тогда как tech-цели дорожают.

Для **неоценённых модовых вещей, дошедших до общего fallback**, вводится разрыв:
**ставка ≤32, награда ≥512**. Он не применяется к явным override-тегам, известным
профилям и распознанным материальным формам. Это уменьшает риск обмена дешёвой
вещи с большой прочностью/редким цветом на дорогую машину и риск выдачи неизвестной
машины за 2. Для такой вещи ставка на ту же вещь **не обязана давать 50%**.

Содержимое, энергия, модули и чары ставки по-прежнему не добавляют ценности.
Износ уменьшает цену. Выигрыш — стандартный экземпляр, ячейки пустые.

## Защита целей, а не полный запрет предметов

Только в Evolution-профиле не выдаются:

- предметы с `c:hidden_from_recipe_viewers`;
- `c:ores`, `c:raw_materials`, `c:storage_blocks/raw_*` и ancient debris:
  дешёвая награда-сырьё не должна превращаться в несколько дорогих слитков;
- namespace `compressedblocks`: нельзя отдавать за общий fallback блок с неизвестным
  количеством распаковываемых ресурсов;
- все `ftbevolution:*`, **кроме проверенных `ruby_gem` и `xy_aluminum_dust`**.
  Это намеренно широкий временный запрет: затрагивает также диск/яблоко/сигилы и
  другие неэндгейм-вещи. Для непроверенных custom-ставок консервативная цена 4,
  независимо от EPIC-цвета; автоматического распознавания прогресса нет;
- `draconicevolution:*` с `chaos` в пути, `mekanism:pellet_antimatter`,
  `mekanism:antiprotonic_nucleosynthesizer`;
- registry paths `creative_*` / `*_creative`. Это защитная эвристика: не полный
  список всех creative-предметов и не доказательство, что любой совпавший ID creative.

Они **могут быть ставками**, если не запрещены общим blacklist. Явные ограничения
целей проверяются и в каталоге, и сервером при выборе/старте; клиентский пакет с ID
не обходит их. Ранее запрещённые technical/component-only предметы остаются запрещены.

Это **не персональные стадии**: пользователь не открывает цели прохождением квестов.
Не все способы обхода прогрессии закрыты — обычные готовые машины по-прежнему
можно выиграть. Ограничение 32767 делает часть эндгейма равноценной; для серьёзной
экономики понадобится следующий проход по рецептам, а не обещание идеального баланса.

## Администратору

- Override-теги `ludocraft:value/<число>` по-прежнему выше профиля; если тегов
  несколько, выигрывает максимальный. Они назначают одинаковую базовую цену ставки/цели.
- Новый `ludocraft:ludka_target_blacklist` запрещает только награду и работает в любом
  профиле. Общий `ludka_blacklist` запрещает обе стороны и имеет приоритет.
- `ludocraft:evolution_target_allowlist` снимает **только** ограничения профиля с
  отдельных целей. Не обходит общий/target blacklist и feature flags. Разрешая custom
  предмет, одновременно задайте ему override-цену — иначе он может стоить всего 4.
- Все эти теги обычные Minecraft item tags и поддерживают optional IDs. Можно
  добавлять, например, `{"id":"ftbevolution:music_disc","required":false}`.
- Маркер активации: тег `ludocraft:balance/ftb_evolution_1_47_0` содержит
  `ludocraft:pocket_ludka`. Базовый JAR поставляет его пустым.
- После `/reload` переоткрыть каталог, чтобы обновились цены/фильтры клиента.

## Тестирование

Команда: `./gradlew build runGameTestServer runEvolutionGameTestServer`.

**Подтверждено:** [Actions 43569796771](https://github.com/nightmare-huy/LudoCraft-/actions/runs/43569796771)
успешно завершился: 8/8 обычных и 2/2 профильных GameTests, чистые тесты и проверка
содержимого JAR/ZIP. [Релиз 1.5.0](https://github.com/nightmare-huy/LudoCraft-/releases/tag/v1.5.0)
опубликован из коммита `1e3e5f2149232f45f4396a41b1dc8b6a006efd42`; повторная проверка
не меняла игрового кода и не перезаписывала релиз.

- Чистые Java-тесты: цены/формы, конверсии 1:1, progression guards, fallback ≤32/≥512,
  шансы, граница между 256k и 1m, прежние вероятности/анимация.
- Обычный GameTest-сервер: восемь прежних тестов без профиля.
- Отдельный GameTest-сервер: настоящий распространяемый datapack, отдельный мир,
  два теста активации, оценок, приоритета override-тегов, target-only blacklist,
  hidden/allowlist, сырья и блоков сырья, серверных котировок/запросов/расхода.
  Тестовый дополнительный datapack находится в `src/test`, в релиз не входит.
- Сторонние моды не устанавливаются в CI. Проверка на реальной FTB Evolution 1.47.0,
  рендеринг клиента и два клиента на сервере остаются ручными проверками.

Перед основным миром сделать резервную копию и проверить на тестовом мире:
активацию заголовка, diamond→controller, FTB Materials dust/ingot, отсутствие hidden
дубликатов/Пирамиды/руд, ставки сырьём, пустые ячейки, `/reload` и отключение профиля.
