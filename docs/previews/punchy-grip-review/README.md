# Сверка хвата с алмазной киркой — проба, не релиз

- Кадры сняты в Minecraft Java 1.21.1, NeoForge 21.1.265 и Punchy 3.2b с настройками по умолчанию.
- `punchy-grip-vanilla-reference.png` — ванильная алмазная кирка; `punchy-grip-released.png` — LudoCraft 1.5.3; `punchy-grip-match-diamond.png` — тест под трансформами алмазной кирки; `punchy-grip-match-diamond-left.png` — левый хват.
- В пробе берутся настоящие first-person display transforms модели алмазной кирки и её фактический профиль Punchy; оба применяются к модели LudoCraft только во время теста. Точные значения записываются в `punchy-grip-profiles.json`.
- Файлы модели и опубликованный JAR не менялись. Кандидат использует временный ресурс-пак и runtime-подмену только в тестовом клиенте. Новый релиз не выпускался.
- Это автоматическое сравнение в изолированном клиенте, не ручная проверка полного FTB Evolution. Шейдеры, пользовательские настройки Punchy и все фазы анимаций не покрыты.
