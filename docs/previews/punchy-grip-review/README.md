# Проверенная поза кирки для Punchy 3.2b

Эти автоматические кадры показывают сравнение опубликованной позы 1.5.3 с обычной алмазной киркой и точной позой, вошедшей в исправление 1.5.4. Minecraft Java 1.21.1, NeoForge 21.1.265, Punchy 3.2b, стандартные настройки.

- `punchy-grip-vanilla-reference.png` — алмазная кирка.
- `punchy-grip-match-diamond-size.png` и `...-left.png` — новая 3D-модель в правой/левой руке.
- Воспроизведён ванильный угол, а объёмная головка уменьшена до 75%. Проверяется дополнительный сдвиг на 0,5 модельного пикселя вниз к ладони сверх уже выпущенного сдвига на 2 пикселя внутрь.
- `punchy-grip-profiles.json` содержит фактические профили Punchy и first-person transforms, снятые в клиенте.
- Сборный лист использует реальные игровые кадры без ретуши. В `docs/previews/v1.5.4/README.md` — релиз, дополнительная проверка добычи/восстановления и её ограничения.
