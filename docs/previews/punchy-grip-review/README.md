# Сверка хвата с алмазной киркой — проба 75%, не релиз

- Кадры сняты в Minecraft Java 1.21.1, NeoForge 21.1.265 и Punchy 3.2b с настройками по умолчанию.
- `punchy-grip-vanilla-reference.png` — алмазная кирка; `punchy-grip-released.png` — LudoCraft 1.5.3; `punchy-grip-match-diamond-size.png` — проба с тем же углом и точкой хвата, 3D-модель уменьшена до 75%; `punchy-grip-match-diamond-size-left.png` — левая рука.
- Снимки показывают фактическую модель в игровом клиенте. Кандидат использует реальные transforms и стандартный Punchy-профиль алмазной кирки; уменьшен только размер объёмной модели, чтобы её широкая головка помещалась в кадр.
- Папка содержит только тестовые кадры. Новый JAR публикуется лишь после прохождения штатных проверок модели и обоих игровых клиентов.
- Это автоматическое сравнение в изолированном клиенте, не ручная проверка полного FTB Evolution. Шейдеры, пользовательские настройки Punchy и все фазы анимаций не покрыты.
