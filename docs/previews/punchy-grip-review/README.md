# Punchy grip preview — эксперимент, не релиз

- Игровые кадры сняты автоматически в Minecraft Java 1.21.1, NeoForge 21.1.265, Punchy 3.2b с настройками по умолчанию.
- `punchy-grip-vanilla-reference.png` — алмазная кирка; `punchy-grip-released.png` — опубликованная поза LudoCraft 1.5.3; `punchy-grip-proposed*.png` — временный тестовый вариант.
- Попытка: увеличить размер кирки до 1,15 и сдвинуть точку положения в Punchy по `offZ` на +0,35 блока; небольшая зеркальная коррекция `offX` ±0,08. Сами кадры не ретушировались. Фактические исходные параметры 1.5.3 записаны в `punchy-grip-profiles.json`.
- Этот кандидат загружался только отдельным временным ресурс-паком теста. Опубликованный JAR, его JSON совместимости, модель и текстура **не менялись**. Никакой новый релиз не выпущен.
- Это изолированный тест Punchy, не ручная игра в FTB Evolution; пользовательские настройки Punchy, шейдеры и полный набор анимаций не проверялись. Кадры нужны, чтобы сначала согласовать сам вид хвата.
